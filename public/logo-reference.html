How to use this

The watch is a single inline SVG (the <symbol id="mnstr-watch"> at the top of this file). The mascot lives in a separate <image-slot> positioned over the dial — swap the mascot art without re-cutting the watch.

For the dashboard: lift the <symbol> into a shared SiteIcon React component, take a mascot URL as a prop, and ship.

Production checklist

  • Export mnstr-watch.svg (mark only, no mascot) → CDN root
  • Export mascot art at 256, 512, 1024 → CDN root
  • Generate favicon.ico (16/32/48 multi-size), favicon-192.png, favicon-512.png, apple-touch-icon.png (180)
  • Generate og-default.png (1200×630) — server-render via @vercel/og from this template
  • Update dashboard <TopBar> to use <SiteIcon size={36}/> + the blackletter wordmark
  • Add site.webmanifest with name "MnStr · Watch", theme color #d6a04a, background #1a1812
